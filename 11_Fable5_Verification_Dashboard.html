스펙 & API

2026-06 시점 라인업 5모델의 스펙 비교와 Fable 5 고유의 API 동작(refusal·thinking·과금)·폴백 아키텍처입니다.

5모델 스펙 비교

API 동작 4가지

① Refusal 응답 T1
HTTP 200 + stop_reason:"refusal"
에러가 아닌 정상 응답으로 반환되며 stop_details가 함께 제공됨. 클라이언트는 stop_reason 분기 처리 필수.
② Thinking 표시 T1
raw CoT 미반환
thinking.display:"summarized"만 가능 — 요약된 thinking만 노출.
③ Thinking 비활성화 T1
{"type":"disabled"} 미지원
adaptive thinking이 항상 on — thinking을 끌 수 없음.
④ Classifier 차단 과금 T1
무과금 · rate limit 미카운트
output 생성 전 classifier block은 과금·rate limit에 미포함. fallback_credit_token으로 cache-write→cache-read 재가격.

폴백 아키텍처

Server-side Fallback beta

Claude API · Claude Platform on AWS만 지원
claude-fable-5→ claude-opus-4-8→ (chain 최대 3)
API가 서버에서 자동 폴백. streaming은 partial output 유지, non-streaming은 폴백 모델이 새로 응답.

Client-side SDK Middleware

Bedrock / Vertex AI / Microsoft Foundry — 클라이언트 측 처리 필요
SDK middleware→ refusal 감지→ claude-opus-4-8 재호출
3rd-party 채널은 server-side fallback 미지원 — BetaRefusalFallbackMiddleware로 클라이언트에서 처리.
PYTHONclient-side SDK middleware (Bedrock/Vertex/Foundry)
from anthropic import Anthropic
from anthropic.beta.fallback import BetaRefusalFallbackMiddleware

client = Anthropic(
    middleware=[BetaRefusalFallbackMiddleware([{"model": "claude-opus-4-8"}])]
)

resp = client.beta.messages.create(
    model="claude-fable-5",
    max_tokens=2048,
    messages=[{"role": "user", "content": "Analyze this large architecture document"}],
)
TYPESCRIPTserver-side fallback (Claude API, beta)
const response = await client.beta.messages.create({
  model: "claude-fable-5",
  max_tokens: 2048,
  messages,
  betas: ["server-side-fallback-2026-06-01"],
  fallbacks: [{ model: "claude-opus-4-8" }]
});
